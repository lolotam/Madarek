# طبقة الشرح المتحرك — القرارات والإعداد

هذا الملف يجيب سؤالين: **ماذا نستخدم لكل نوع حركة**، و**ما الذي تحتاج تثبيته محليًا وربطه عبر MCP** حتى يصبح سير العمل: تعطي صور الدرس → تختار السكيل → يُبنى الدرس.

آخر تحديث: 2026-09-22.

---

## 1. القرار لكل طبقة

| الطبقة | الأداة | الحالة اليوم | متى ننتقل للتالي |
| --- | --- | --- | --- |
| واجهة التطبيق، الكروت، التبويبات، حالات الإجابة | **Framer Motion 13** (مثبّتة) | ✅ مستخدمة | — |
| شرح متحرك، علاقات، ترتيب وتصنيف | **Motion + SVG** | ✅ مُنفّذ في درس المغذّيات (`lesson-diagrams.tsx`, `lesson-drills.tsx`) | — |
| مشهد شرح طويل مربوط بالتمرير (pin + scrub) | **GSAP + ScrollTrigger** | ❌ غير مثبّت — **وهذا مقصود** | عند وجود درس يحتاج تثبيت المشهد أثناء التمرير فعلًا: دورة الماء، الجهاز الهضمي، دوران الأرض |
| شخصية مرافقة ورسوم جاهزة | **Rive / Lottie** | ❌ غير مثبّت | مرحلة تحسين إضافية بعد أن تثبت الحركة التعليمية فائدتها |
| مجسّمات ثلاثية الأبعاد | **Three.js + React Three Fiber** | ❌ غير مثبّت | عند أول درس يحتاج مجسّمًا فعلًا (الخلية، النظام الشمسي، طبقات الأرض) |

### لماذا لا GSAP الآن

Framer Motion 13 المثبّتة عندنا تصدّر `animate()` مع `AnimationSequence` و`useAnimate` و`scroll()` و`useScroll`، أي أن «التسلسل الدقيق» و«الربط بالتمرير» متاحان بلا مكتبة ثانية. إضافة GSAP اليوم تعني نظامَي حركة متوازيين في نفس الصفحة وحجمًا إضافيًا بلا مقابل.

**شرط الانتقال:** أول درس نحتاج فيه إلى **تثبيت (pin)** قسم من الشاشة وربط تقدّم الحركة بموضع التمرير (`scrub`) بدقة. عندها نضيف `gsap` + `@gsap/react` ونستخدم `useGSAP` في مكوّن عميل واحد فقط، مع بديل نصّي ثابت لمن فعّل «تقليل الحركة».

### لماذا لا Blender ولا Spline

- **Blender مستبعد بقرارك** (لا إعداد محلي). لا نعتمد عليه في أي مسار.
- **Spline** متاح كـ MCP في هذه الجلسة، لكن مسار التصدير/النشر مرتبط بخطة مدفوعة — تحقّق من خطتك قبل الاعتماد عليه. لسنا بحاجته.
- **البديل المعتمد:** أشكال R3F الأساسية (كرة، أسطوانة، طبقات) + خامات مولّدة. لدرس مدرسي مثل «الخلية» أو «طبقات الأرض» هذا يكفي تمامًا ويُغني عن أنبوب النمذجة كله.
- **إن احتجنا مجسّمًا معقّدًا:** أداة `atlas_generate_image` في خادم atlascloud تغطّي أيضًا نماذج text-to-3D وترجع ملف `.glb` جاهزًا — يُعرض مباشرة في R3F بلا Blender ولا Spline. البديل الثاني ملف GLB برخصة CC0. راجع القائمة بـ `atlas_list_models` قبل اختيار موديل.

## 2. الإعداد المحلي

### اليوم: لا شيء

طبقة Motion + SVG تعمل بما هو مثبّت (`framer-motion@13.4.0`, `next@16.3.5`, `react@19.3.0`). لا تثبّت شيئًا الآن.

### عند أول درس 3D

```bash
npm i three @react-three/fiber @react-three/drei
npm i -D @types/three
```

قواعد إلزامية عند الدمج (وإلا ينهار الأداء على موبايل الطالبة):

- حمّل المشهد بـ `next/dynamic` مع `ssr: false`، وبعد تفاعل المستخدمة لا عند فتح الصفحة.
- `<Canvas dpr={[1, 2]} frameloop="demand">` وأعِد الرسم عند التغيير فقط.
- وفّر بديلًا ثابتًا: صورة + نص يشرح نفس الفكرة، ويظهر عند `prefers-reduced-motion` أو فشل WebGL.
- المجسّم لا يحمل معلومة وحده أبدًا — النص المجاور هو مصدر الفهم (نفس قاعدة الرسوم الحالية).

تحقّق من توافق إصدارات R3F مع React 19 وقت التثبيت قبل اعتمادها.

### عند أول مشهد مربوط بالتمرير

```bash
npm i gsap @gsap/react
```

## 3. إعداد MCP

### متصل فعلًا في هذه الجلسة — لا يحتاج عملًا

| الخادم | الاستخدام في سير العمل |
| --- | --- |
| `atlascloud` | توليد الصور: `atlas_generate_image` بالموديل `openai/gpt-image-2-developer/text-to-image`، جودة **low**، ونسبة الأبعاد من مقاس الـ slot |
| `playwright` / `claude-in-chrome` | فتح الصفحة، التقاط لقطات 360px و1280px، قراءة أخطاء الـ console |
| `Spline` | اختياري لمشاهد 2D/3D — غير معتمد في المسار الحالي |
| `vercel` / `dokploy-*` / `ssh-*` | النشر والمتابعة |

### متعطّل الآن — أصلحه إن احتجته

`higgsfield` (انتهاء مهلة)، `plugin:desktop-commander` (انتهاء مهلة)، `n8n-mcp` (SSL 525)، `plugin:data:definite` (عنوان غير موجود)، `ssh-Abdelaziz-mcp` (انقطاع). لا شيء منها مطلوب لبناء الدروس.

### ما لا أنصح بإضافته الآن

- **Manim MCP**: يحتاج Python وLaTeX محليًا، ومخرجه فيديو لا عنصر تفاعلي. أنيميشن SVG عندنا أخفّ ويتفاعل مع الطالبة.
- **Blender MCP**: مستبعد بقرارك.
- **Quiz MCP**: لدينا محرّك أسئلة وتصحيح على الخادم بالفعل (`src/server/questions.mjs`) مع حفظ المحاولات والمكافآت. خادم خارجي سيكرّر ما نملكه ويفكّ ربطه بحساب الطالبة.

### إن أردت تثبيت الإعداد للمشروع لا للجهاز

أنشئ `.mcp.json` في جذر المستودع بالخوادم التي يحتاجها المشروع فقط (`atlascloud`, `playwright`)، فيراها أي جلسة تفتح المجلد. لا تضع مفاتيح API داخله؛ اتركها في متغيّرات البيئة.

## 4. سير العمل المطلوب

1. ضع مراجع الدرس في مكانها: صفحات الكتاب تحت `GRADE-8/FIRST-TERM/...`، وأي صور تعطيها أنت تحت `docs/lessons/<lesson-id>/refs/`.
2. شغّل السكيل: `/lesson-explainer <اسم الدرس>`.
3. السكيل يتولّى: المحتوى → تسجيل خانات الصور وتوليد الناقص منها → صفحة الدرس بالشرح المتحرك والأنشطة → بنك الأسئلة → اختبار متصفح → فحص الأنواع والبناء والاختبارات → لقطات 360/1280 → توثيق مصدر الصور.

تفاصيل ما يفعله ومحاذيره في `.claude/skills/lesson-explainer/SKILL.md`.

## 5. نقطة تحتاج قرارك

طلبك «كل الأيقونات والصور hyper realistic» طبّقته على **صور المحتوى** (أطعمة، أدوات، عيّنات): واقعية تمامًا كما في `image-slots.ts`.

أما **أيقونات الواجهة** (lucide في الأزرار والبطاقات، مقاس 16–26px) فأبقيتها خطّية: الأيقونة الواقعية بهذا المقاس تتحوّل إلى بقعة غير مقروءة وتكسر التباين المطلوب. إن كنت تقصد أيقونات واقعية داخل بطاقات كبيرة (مثل بطاقات المغذّيات) فهذا ممكن — قل لي وأنفّذه كخانات صور مولّدة.
