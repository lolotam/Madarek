# مراجعة الموقع المنشور وتحسيناته — 2026-09-19

الموقع: https://madarek.walidmohamed.com/

## ما تحقق على النسخة المنشورة قبل التعديل

- الرئيسية والفهرس ودرس المغذيات والتسجيل تعمل عبر HTTPS وتعيد 200.
- لا صور مكسورة رُصدت في الصفحات المفحوصة، ولا تجاوز أفقي بعرض 390 بكسل.
- لا أخطاء JavaScript أثناء اختبار التبديل إلى المغذيات الصغرى.
- فحص Axe آلي بمعايير WCAG A/AA على الصفحات الأربع أعاد صفر مخالفات. هذا ليس تدقيق وصول بشريًا شاملًا.
- البحث عن «المغذيات» دون شدة يعيد صفر دروس، رغم وجود درس «المغذّيات».
- روابط الوحدات تبقى ظاهرة بعد إخفاء الأقسام بالبحث، فتشير إلى أهداف غير موجودة.
- قائمة الموبايل تبقى مفتوحة بعد Escape.
- `robots.txt` و`sitemap.xml` يعيدان 404، ولا توجد بيانات مشاركة مخصصة لكل صفحة.
- التسجيل والتذييل لا يزالان يصفان الموقع بأنه «نسخة محلية».
- خدمة الصوت تعيد 49 مقطعًا كلها `not_ready`. لم يولّد هذا العمل صوتًا ولم يستخدم مفاتيح ElevenLabs.
- النسخة المنشورة لا تعرض بعد إصلاح حالة الصوت غير الجاهز الموجود مسبقًا في الالتزام `657b06d`؛ لم يُنسب هذا الإصلاح إلى التحسينات الجديدة.

## التحسينات المنفذة

- بحث عربي يتجاهل التشكيل والتطويل ويفهم صور الألف والياء والتاء المربوطة الشائعة. البحث بعدة كلمات يقبل اختلاف ترتيبها.
- عدد نتائج معلن لقارئ الشاشة وزر لمسح البحث، مع إخفاء روابط الوحدات التي ليس لها نتائج.
- أرقام الدروس بالعربية، مع الاحتفاظ برقم الدرس الأصلي بعد التصفية.
- إغلاق قائمة الموبايل بـ Escape مع استعادة التركيز، وبالضغط خارجها أو انتقال التركيز خارج الرأس. إضافة علاقة الزر بالقائمة وحالة رابط الصفحة الحالية.
- بيانات canonical وOpen Graph وTwitter للصفحات العامة على النطاق الصحيح، باستخدام الصور الواقعية الموجودة.
- robots وخريطة موقع تضم الرئيسية والفهرس والدرس المنشور فقط؛ لا تُدرج صفحات الحسابات والإدارة. الدرس غير المنشور يحصل على noindex ويخرج من الخريطة.
- تعليمات التسجيل تشرح حفظ تقدم الأسرة وعدم توافر استعادة كلمة المرور بالبريد؛ إزالة وصف «نسخة محلية» من المنتج المنشور.

## التحقق المحلي

- `npm run build`: ناجح.
- اختبارات المتصفح القائمة للتعلم والتسجيل وعدم تجاوز أربعة مقاسات: 3 ناجحة.
- اختبار الوصول الآلي المحلي: ناجح.
- اختبارا التغذية الراجعة والصوت غير الجاهز: ناجحان.
- ثلاثة اختبارات جديدة للبحث العربي والقائمة وبيانات الفهرسة والمشاركة: ناجحة.
- أخفق التحقق الأول في اختبارين بسبب اختيار نقطة تغطيها القائمة وافتراض شرطة مائلة نهائية في رابط canonical؛ صُحّحت افتراضات الاختبار وأُعيدت الاختبارات الثلاثة بنجاح.
- تحقق بصري مستقل لنتيجة البحث على الموبايل: درس واحد صحيح ولا تجاوز أفقي.
- لم تُنشأ حسابات اختبار في الإنتاج، ولم تُعدّل بيانات الأسر أو إعدادات الخادم أو النشر أو الصوت.

## النشر

التحديث يُرسل إلى مستودع GitHub. تأكيد نجاح البناء والاختبارات محليًا لا يثبت وصوله إلى الإنتاج. يتحقق الوصول بظهور البحث المصحح و`/robots.txt` و`/sitemap.xml` على الدومين. إذا كان Dokploy مضبوطًا للنشر اليدوي، يُستخدم Deploy لجلب الالتزام الجديد، وفق `docs/DEPLOYMENT.md`.
