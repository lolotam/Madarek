# مدارك — علوم الصف الثامن

اسم عمل مؤقت لمنصة تعلم عربية. النسخة المحلية الحالية تركز على علوم الصف الثامن، الفصل الأول 2026–2027. لم يبدأ استيعاب باقي الصفوف أو المواد.

## التشغيل

يلزم Node.js 24 أو أحدث. من جذر المشروع:

```powershell
npm.cmd ci
npm.cmd run dev -- --hostname 127.0.0.1 --port 3000
```

افتح `http://127.0.0.1:3000`. لتشغيل بناء الإنتاج محليًا:

```powershell
npm.cmd run build
npm.cmd start -- --hostname 127.0.0.1 --port 3000
```

الحسابات والمحاولات محفوظة في `.data/learning.sqlite`. لا تحذف هذا المجلد إذا أردت الاحتفاظ بالتقدّم. لا توجد حسابات افتراضية أو كلمات مرور عامة. ملفات المصادر الأصلية لا تُنقل ولا تُنشر من مجلد `public`.

## المتاح في هذه النسخة

- رئيسية عربية RTL متجاوبة، مع هيرو مرسوم، كروت الصفوف وكاروسيل قابل للتحكم.
- فهرس العلوم مطابق للكتاب المرفوع: أربع وحدات، تسعة فصول و19 درسًا؛ المغذّيات متاح والباقي «قريبًا».
- شرح المغذّيات مع شجرة تفاعلية، مستكشف أطعمة، خطوات متحركة للطاقة والبناء والإصلاح، ومحتوى عن الماء والفيتامينات والأملاح والألياف.
- تدريب اختاري وعلّلي، واختبار نهائي من ستة اختيار متعدد وأربعة أكملي مع تفسير ودرجة وإعادة محاولة.
- تسجيل الأسرة في خطوة واحدة: ولي الأمر بالبريد وكلمة المرور، ومعه حتى ستة أبناء؛ لكل ابن اسم وصف (الثاني أو الخامس أو الثامن) وجنس واسم مستخدم ورمز من 6–12 رقمًا. يُقبل الحساب فورًا دون تحقق بريد ويُسجَّل دخول ولي الأمر مباشرة. يُحفظ كل شيء أو لا شيء في معاملة واحدة. الجنس محفوظ فقط، ولم تتغير صياغة الموقع بحسبه بعد.
- دخول الطفل مستقلًا باسم المستخدم والرمز، وإضافة أبناء لاحقًا من لوحة ولي الأمر.
- لوحة الطالب وولي الأمر: المقاطع المنجزة، آخر وأفضل درجة، المحاولات وإجاباتها وتدريب علّلي وموضوعات المراجعة.
- صلاحيات على الخادم وعزل الأسر وجلسات HttpOnly وتجزئة كلمات المرور وتقييد تكرار محاولات الدخول.
- إعادة تعيين رمز الطفل بواسطة ولي أمره مع إنهاء الجلسات القديمة.
- لوحة الإدارة `/admin` (للمدير فقط):
  - **المستخدمون:** البحث في الأسر، وتعديل ولي الأمر والأبناء، وإعادة تعيين كلمة المرور أو الرمز.
  - **تعطيل الحسابات وتفعيلها:** يُنهي التعطيل الجلسات فورًا.
  - **إنشاء أسرة وحذفها:** الحذف بكتابة بريد ولي الأمر للتأكيد.
  - **الحماية على الخادم:** لا يعطّل المدير حسابه أو يحذفه، ويبقى مدير مفعّل واحد على الأقل.
  - **إعدادات الخدمات:** معرّف صوت ElevenLabs والموديل وحد الحروف، ومفتاح API مشفّر بـ AES-256-GCM يُكتب ولا يُعرض (آخر أربعة أحرف فقط).
  - **المحتوى:** النشر والإحصاءات.
  - **السجل:** كل إجراء إداري، دون أسرار.
- الشرح الصوتي المصري المتزامن لدرس المغذّيات (راجع القسم التالي).

يمكن للزائر تجربة الشرح والاختبار دون حفظ. حساب ولي الأمر يعاين الدرس أيضًا؛ حفظ تقدم الطفل ودرجاته يتطلب الدخول **بحساب الطفل**. لا تُحسب إجابة «علّلي» ضمن الدرجة النهائية.

## الشرح الصوتي

التصميم في `docs/AUDIO-NARRATION-DESIGN.md`. المنفذ الآن في المرحلة الأولى (درس المغذّيات):

- **النصوص:** 77 مقطعًا مصريًا مراجعًا في `src/server/narration/nutrients.json` (نحو 8,200 حرف)، مع إشارات تزامن. مقاطع الإجابات والتفسيرات محمية ولا تُقدَّم إلا بعد التصحيح.
- **المشغّل في الدرس:**
  - «اسمعي الصفحة»، وتشغيل كل جزء، وقراءة النتيجة.
  - إيقاف مؤقت، ومن الأول، والسابق والتالي، والبحث، والسرعة، والتكرار.
  - إطار متحرك (Framer Motion) يتبع العنصر المشروح ويفتح التبويب أو الطعام أو الخطوة في وقتها. أي تفاعل يدوي يوقف الصوت.
- **الخادم:** لا يقدّم إلا المقاطع المعتمدة، مع دعم HTTP Range للبحث.

الصوت نفسه **لم يُولَّد بعد**. حتى يُولَّد ويُعتمد، يعرض الدرس «الشرح الصوتي غير جاهز بعد» ويبقى كاملًا بدونه. للتوليد:

1. اضبط المفتاح ومعرّف الصوت وحد الحروف `ELEVENLABS_MAX_CHARACTERS` من لوحة الإدارة أو في `.env.local`.
2. شغّل:

```powershell
npm.cmd run audio -- plan
npm.cmd run audio -- generate
```

`plan` لا يتصل بالشبكة ويعرض عدد الحروف المطلوب. `generate` يرفض العمل دون حد للحروف، ويطلب تأكيدًا، ويحفظ كل مقطع في `.data/audio/` بحالة «قيد المراجعة».

3. استمع لكل مقطع في `/admin/audio`، ثم اعتمده أو ارفضه مع ذكر السبب. النص يُظلَّل أثناء الاستماع للتحقق من التزامن. لإعادة توليد المرفوض:

```powershell
npm.cmd run audio -- generate --retry-rejected
```

المقطع المعتمد لا يُستبدل تلقائيًا أبدًا. مجلد `.data/audio/` غير محفوظ في Git؛ انسخه احتياطيًا مع قاعدة البيانات.

## إنشاء مسؤول محلي

أنشئ حساب ولي أمر منفصلًا للإدارة من شاشة التسجيل، واحذف صف الطالب من النموذج حتى لا يُضاف إليه أبناء. ثم شغّل محليًا:

```powershell
npm.cmd run admin -- owner@example.com
```

استبدل البريد ببريد الحساب الذي أنشأته. تسجيل الدخول التالي لهذا الحساب يفتح لوحة الإدارة، ومنها `/admin` و`/admin/audio`. لا يستطيع التسجيل العام تعيين دور مدير. تغيير الدور يُنهي جلساته القديمة. حساب الإدارة منفصل عن حساب الأسرة حتى لا تضيع وظيفة متابعة الأبناء.

## ما لم يُفعّل بعد

- توليد مسودات من PDF والصور بواسطة الذكاء الاصطناعي والمحرر العام للوحدات والدروس. المتاح الآن هو المحتوى المنسق بالكود ولوحة نشر الدرس الأول.
- تقييم «علّلي» بالذكاء الاصطناعي؛ يظهر نموذج الإجابة مع تنبيه صريح بدلًا منه، وتُحفظ إجابة الطالب.
- استعادة كلمة مرور ولي الأمر بالبريد؛ مزود البريد لم يُربط. التسجيل مقبول دون تحقق بريد بقرار من المالك؛ يعيد المدير تعيين كلمة المرور عند الحاجة.
- توليد الصوت الفعلي ومراجعته سمعيًا، واختيار الصوت النهائي وحد الحروف.
- صياغة الموقع بحسب جنس الطفل.
- نشر إنتاجي على الإنترنت وربط نطاق، واستكمال سياسة الخصوصية والموافقة وإجراءات حذف البيانات والنسخ الاحتياطي. لا تعتبر هذه النسخة جاهزة للتسجيل العام على الإنترنت.
- الصور الجديدة: تُسجَّل كمواضع مؤقتة في `src/content/image-slots.ts` لتوليدها وربطها لاحقًا.
- بقية الدروس والمواد والصفوف؛ إضافة ملفات جديدة لا تنشر دروسها تلقائيًا.

الإصدار مجاني للمستخدم وفق PRD؛ تشغيل APIs أو استضافة لاحقًا يحتاج إعدادًا وميزانية منفصلين. لم تُرفع ملفات الكتب أو بيانات الأطفال إلى خدمة خارجية خلال التنفيذ.

## التقنية والتصميم

Next.js وReact وTypeScript، مع HTML وCSS وTailwind وFramer Motion (لكل الحركات الجديدة) وRadix Tabs وRadix Dialog وLucide. خط Noto Sans Arabic مُضمّن محليًا. قاعدة SQLite محلية خلف الخادم؛ ليست localStorage أو بيانات واجهة وهمية. يمكن استبدال مستودع البيانات بقاعدة إنتاج لاحقًا دون تغيير تجربة الدرس.

استُخدمت مهارات `ui-styling` و`ui-ux-pro-max` بناءً على طلب وليد. قواعد التصميم الخاصة بالمشروع في `design-system/hana-learning/pages/platform.md` تتقدم على ألوان وخطوط التوصية العامة: العربية والباليت الجديدة المعتمدة: Amber Gold `#ffbe0b`، Blaze Orange `#fb5607`، Neon Pink `#ff006e`، Blue Violet `#8338ec`، Azure Blue `#3a86ff`.

## الاختبارات

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run test:e2e
```

- اختبارات Node، وتشمل:
  - التصحيح وتطبيع الإجابات وسرية مفاتيح الاختبار؛
  - الصلاحيات وعزل الأسر والمحاولات وإبطال الجلسات واستمرار البيانات؛
  - تسجيل الأسرة والترحيل؛
  - الإدارة والتشفير والسجل؛
  - مكتبة الصوت والمحاذاة والتصاريح وأوامر التوليد مع fetch وهمي، دون أي اتصال فعلي بـ ElevenLabs.
- اختبارات Playwright:
  - تعمل على بناء الإنتاج وChrome المثبت محليًا، على المنفذ 3001 أو `E2E_PORT`.
  - تستخدم `.data/browser-qa.sqlite` ومكتبة `.data/audio-e2e` منفصلتين عن بيانات التطبيق.
  - تغطي المشغّل والتزامن ولوحة الإدارة ومراجعة الصوت.
- فحص أربعة عروض: 360 و768 و1440 و844 بكسل، وتفاعل الشجرة والطعام والتجربة، ورحلة إنشاء الأسرة والطفل والإجابة والمتابعة.
- فحص Axe الآلي على الرئيسية والفهرس والدرس والتسجيل، مع مراجعة بصرية منفصلة. نجاح الفحص الآلي لا يعادل تدقيق إمكانية وصول بشريًا كاملًا.

يجب أن يكون المنفذ 3001 متاحًا عند الاختبارات. في بيئة دون Chrome، ثبّت متصفح Playwright واضبط `channel` في `playwright.config.ts`.

## متغيرات البيئة

- `DATABASE_PATH`: اختياري، مسار قاعدة البيانات؛ الافتراضي `.data/learning.sqlite`.
- `APP_ORIGIN`: اختياري محليًا، **مطلوب في الإنتاج** (مثل `https://madarek.walidmohamed.com`). يثبّت التحقق من مصدر طلبات التعديل، ويجعل كوكي الجلسة Secure خلف proxy. عند غيابه تُستخدم ترويسات `X-Forwarded-Proto` و`X-Forwarded-Host`.

- `SETTINGS_ENCRYPTION_KEY`: مفتاح 32 بايت (base64 أو 64 خانة hex) لتشفير مفاتيح الخدمات المحفوظة من لوحة الإدارة. من دونه تُعطَّل حقول الأسرار في اللوحة، ولا يُحفظ أي سر دون تشفير. تغييره يجعل الأسرار المحفوظة غير قابلة للقراءة.
- `ELEVENLABS_API_KEY` و`ELEVENLABS_VOICE_ID` و`ELEVENLABS_MODEL_ID` (الافتراضي `eleven_multilingual_v2`) و`ELEVENLABS_MAX_CHARACTERS`: بدائل عند غياب القيم في لوحة الإدارة، فإعدادات القاعدة تتقدم. `ELEVENLABS_OUTPUT_FORMAT` اختياري.
- `AUDIO_LIBRARY_PATH` (الافتراضي `.data/audio`) و`NARRATION_DIR` (الافتراضي `src/server/narration`).
- `E2E_PORT`: منفذ اختبارات Playwright، الافتراضي 3001.

القيم الفارغة موثقة في `.env.example`. لا تضع مفاتيح الخدمات في مكونات العميل، ولا تحفظ ملفات `.env` في Git.

على Windows لا تشغّل `npm ci` أثناء عمل خادم المشروع؛ الخادم يقفل ملفات Next الأصلية فيفشل الحذف في منتصف التثبيت. أوقف الخادم أولًا أو استخدم `npm install`.
